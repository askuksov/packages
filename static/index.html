packages.kuksov.dev

apt and dnf repositories for Linux apps by Oleksandr Kuksov.

1Add the repository

Once per machine. Your package manager then installs and updates the apps below.

Debian, Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/kuksov.gpg \
  https://packages.kuksov.dev/kuksov-archive-keyring.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/kuksov.gpg]" \
  "https://packages.kuksov.dev/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/kuksov.list
sudo apt update

Fedora

sudo curl -fsSLo /etc/yum.repos.d/kuksov.repo \
  https://packages.kuksov.dev/rpm/kuksov.repo
Packages and indexes are signed with this key. dnf asks you to confirm it on the first install. {{FINGERPRINT}}
